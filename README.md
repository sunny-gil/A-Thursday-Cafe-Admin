# ☕ A-Thursday-Cafe-Admin

A premium, modern administrative dashboard for managing the **A-Thursday-Cafe** application. Built with the latest **Angular 21**, **Tailwind CSS**, and **Angular Material**, this admin panel provides a seamless and responsive interface to manage everything from orders to products, categories, blogs, and customer feedback.

---

## ✨ Key Features

- **🔒 Secure Authentication:** Protected routes with JWT-based authentication guards.
- **📊 Interactive Dashboard:** Overview of cafe statistics and performance.
- **🖼️ Banner Management:** Control the promotional banners on the main cafe UI.
- **📦 Order Management:** Track and process customer orders in real-time.
- **🍔 Product & Category Management:** Create, update, and categorize menu items effortlessly.
- **📝 Blog Management:** Publish and manage blog posts for customer engagement.
- **💬 Feedback System:** Review and respond to customer feedback directly.
- **📱 Fully Responsive:** Optimized for both desktop and mobile devices.

---

## 🛠️ Tech Stack

- **Framework:** Angular 21
- **Styling:** Tailwind CSS & Angular Material
- **Real-time:** Socket.IO Client
- **State & Routing:** RxJS & Angular Router
- **Alerts:** SweetAlert2

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed on your machine:
- **Node.js** (v20.x or higher)
- **npm** (v10.x or higher)
- **Angular CLI** (`npm install -g @angular/cli`)

### Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/sunny-gil/A-Thursday-Cafe-Admin.git
   cd A-Thursday-Cafe-Admin
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure Environment Variables:**
   Ensure your backend API URL is configured correctly in your environments configuration.

4. **Run the Development Server:**
   ```bash
   ng serve
   ```
   Navigate to `http://localhost:4200/`. The application will automatically reload if you change any of the source files.

---

## 🏗️ Build & Deployment

To build the project for production, run:

```bash
ng build
```

The build artifacts will be stored in the `dist/` directory.
